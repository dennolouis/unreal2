# Smooth Rotation - Visual Guide

## Before vs After

### Before (Snap Rotation)
```
                N (90°)
                 |
                 |
    W (180°) ---+--- E (0°/360°)
                 |
                 |
                S (270°)

Input: PRESS D (East)
Character at: Facing North (90°)
Immediate Result: SNAP to East (0°)
Duration: Instant
Feel: Jerky, mechanical
```

### After (Smooth Rotation)
```
                N (90°)
                /|
               / |
              /  |  <- Smooth arc
             /   |     over time
    W (180°)----+---- E (0°/360°)
             \   |
              \  |
               \ |
                \|
                S (270°)

Input: PRESS D (East)
Character at: Facing North (90°)
Frame 1: 75° (rotated 15° toward east)
Frame 2: 60° (rotated further)
Frame 3: 45° (halfway)
...
Frame N: 0° (facing east)
Duration: ~0.15-0.3 seconds
Feel: Smooth, natural, responsive
```

## Input Direction Update Timeline

```
Traditional Movement (every frame):
Frame 1: UpdateVelocity() ? LastInputDirection = Forward
Frame 2: UpdateVelocity() ? LastInputDirection = Forward-Right (changed!)
Frame 3: UpdateVelocity() ? LastInputDirection = Right
         ?
Result: Rotation happens every frame (even when not attacking!)

Attack Only (what we want):
Frame 1: Attack starts
Frame 2: ComboAttack() ? SetCameraRelativeInputDirection(Forward)
         ?
         Smooth rotation applies
Frame 3: Player moves stick ? Input updated
Frame 4: Smooth rotation updates toward new direction
Frame 5: Attack ends ? Smooth rotation stops
         ?
Result: Rotation only happens during attacks!
```

## Next Issue Visualization

### Current State (Problem)
```
Standing Still (No Attack):
?? Movement Input: Stick is at Neutral
?? SetCameraRelativeInputDirection(): Called every frame (wrong!)
?? LastInputDirection: Zero
?? Result: No rotation (works OK because zero input)

Walking & Attacking:
?? Movement Input: Stick forward
?? SetCameraRelativeInputDirection(): Called every frame from movement
?? LastInputDirection: Continuously updated to current direction
?? Result: Character rotates to face movement direction (sometimes wanted)
           But also rotates BEFORE attack starts (unwanted)
```

### Desired State (Solution)
```
Standing Still (No Attack):
?? Movement Input: Stick is at Neutral  
?? SetCameraRelativeInputDirection(): NOT called
?? LastInputDirection: Stays as-is
?? Result: No rotation ?

Attacking:
?? Movement Input: Stick moves
?? SetCameraRelativeInputDirection(): Called in attack input (not movement!)
?? LastInputDirection: Updated only when attacking
?? Result: Character rotates to face input DURING attack ?

Walking (No Attack):
?? Movement Input: Stick forward
?? SetCameraRelativeInputDirection(): NOT called
?? LastInputDirection: Stays as previous attack direction
?? Result: Character maintains facing direction while walking ?
```
